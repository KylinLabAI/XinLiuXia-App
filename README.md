# XinLiuXia (心流匣)

[中文](README.zh.md)

![XinLiuXia Logo](resources/logo_256.png)

A lightweight, science-based focus training app with four attention modules, adaptive difficulty and visible progress in short daily sessions.

## Features

- **Four science-backed modules: Schulte Grid, Stroop color conflict, number working memory, rapid attention shifting**
- **Adaptive difficulty adjusting in real time to keep users in an efficient flow range**
- **Progress visualization: four-dimension radar chart, trends, best scores, training duration and streak**
- **Real-time in-session data compared against historical best**
- **Local-first storage, no ads, no pop-ups, no social distraction**
- **Short lightweight sessions for fragmented study and office breaks**
- **Guided first-launch flow**
