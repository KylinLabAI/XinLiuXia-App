# 心流匣 XinLiuXia

[English](README.md)

![心流匣 Logo](resources/logo_256.png)

基于认知神经科学的轻量化专注力训练应用，含四大训练模块与自适应难度，以短时每日练习提升注意力并可视化成长。

## 功能特性

- **四大科学训练模块：舒尔特方格、颜色冲突斯特鲁普测试、数字工作记忆、快速注意力转移**
- **自适应难度算法，依据实时表现动态调节，维持高效心流区间**
- **成长可视化：四维护展能力雷达图、趋势曲线、历史最佳成绩、训练时长与连续打卡**
- **实时对局数据并与历史最佳成绩对比**
- **纯本地计算存储，无广告、无弹窗、无社交干扰**
- **单次训练轻量短时，适配碎片化学习与办公间隙**
- **首次启动引导流程：选择模块 → 完成短时训练 → 查看仪表盘**
